Revisa quines apps i agents d'IA tenen accés als teus comptes

RosmarOps llegeix el que abasten els agents d'IA del teu ordinador. Els agents que funcionen al núvol, i les apps que vas connectar amb «Inicia la sessió amb Google» o semblants, desen el seu accés al compte de cada proveïdor, on RosmarOps no el veu. Cada proveïdor té una pàgina que llista aquest accés. Aquesta et porta fins allà i et diu què cal mirar.

Què cal mirar

Agents i assistents d'IA que ja no fas servir. Accés al teu correu, els teus fitxers, el teu calendari o el teu codi que una app no necessita. Apps que no reconeixes. Apps que no s'han fet servir mai o que fa mesos que no es fan servir: Microsoft i GitHub mostren quan es va fer servir cadascuna per última vegada. Si dubtes, treu l'accés: el podràs tornar a donar la propera vegada que facis servir l'app.

Google

Obre les teves aplicacions vinculades. Mira les apps que tenen accés al teu Gmail, el teu Drive o el teu Calendar, no només aquelles amb què inicies la sessió. El detall de cada app mostra quan li vas donar accés.

Microsoft

Si és un compte personal, obre les aplicacions i els serveis als quals permets l'accés: cada app mostra quan la vas fer servir per última vegada i, a dins, cada permís que té. Si és un compte de feina o d'un centre educatiu, obre Les meves aplicacions; els permisos que va donar el teu administrador només els pot treure ell.

GitHub

Obre Settings › Applications. Revisa les tres pestanyes: GitHub Apps instal·lades, GitHub Apps autoritzades i apps OAuth autoritzades. Les apps OAuth mostren quan es van fer servir per última vegada.

Slack

Obre la gestió d'apps del teu espai de treball. Si el teu espai demana aprovar les apps, només els seus propietaris i els gestors d'apps les poden treure.

Notion

Obre les teves connexions. Cada connexió es pot limitar a les pàgines que hi comparteixes.

Atlassian

Obre les apps connectades del teu compte d'Atlassian. Les apps instal·lades en un lloc de Jira o Confluence les gestionen els administradors del lloc.

Dropbox

Obre les apps connectades. Cadascuna indica si arriba a tot el teu Dropbox o només a la seva pròpia carpeta.

RosmarOps no es connecta a aquests comptes. Enllaços comprovats el 30 d'octubre de 2026.

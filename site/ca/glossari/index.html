Glossari

Els termes que fa servir RosmarOps, en paraules planeres. En aquest web veuràs una «i» al costat: si la prems, l’explicació s’obre allà mateix, sense sortir de la pàgina.

Agent d'IA
Un programa d'intel·ligència artificial que no només contesta: també fa coses per tu, com llegir fitxers, executar ordres o fer servir els teus comptes.
Servidor MCP
Una peça que afegeix eines a un agent d'IA, per exemple per llegir el teu correu o la teva base de dades. Cada servidor MCP que hi afegeixes amplia el que l'agent pot fer.
Connector
Un permís que dones a un agent per entrar en un altre servei teu, com Gmail, Google Drive o GitHub. Mentre està connectat, l'agent pot llegir o canviar el que aquell servei li permeti.
Repositori
La carpeta d'un projecte de codi amb tot el seu historial, normalment a GitHub. També hi ha les instruccions que llegeixen els teus agents quan treballen en aquell projecte.
Clau o credencial
El que dona accés a un servei en nom teu: una contrasenya, un testimoni (token) o una clau d'API. Qui la tingui hi pot entrar com si fossis tu.
Sense preguntar-te
L'agent fa l'acció sense que l'hagis d'aprovar abans. Com més treballa així, més lluny pot arribar si alguna cosa l'enganya.
Automatització
Una tasca que l'agent fa sol, a una hora fixa o quan passa alguna cosa, sense que tu hi siguis.
Entrenar els seus models
Fer servir les teves converses per millorar la IA de l'empresa. No canvia el que l'agent pot fer, però sí qui pot arribar a veure el que escrius.
Banda
El tram de la nota que marca el semàfor: 0–49 exposat, 50–79 amb escletxes i 80–100 contingut. L'avís més greu fixa la banda.
Xifrat
Convertit en una cosa que només pot llegir qui té la clau. RosmarOps xifra els teus resultats abans d'enviar-los.

Què poden fer els teus agents d'IA a la teva màquina.

Un agent d'IA treballa amb els teus permisos: pot llegir els teus fitxers, executar programes i arribar a les claus dels serveis que tens connectats. RosmarOps t'ensenya fins on arriba cada agent del teu ordinador, i si un pot canviar el que fa un altre: un mapa d'exposició, calculat al teu ordinador. Avui posa nota a Claude Code, Cursor i Hermes Agent.

Un informe d'exemple

Això és el que t'ensenya RosmarOps, en un ordinador inventat: la nota de cada agent que avalua, el primer que cal arreglar i quant puja la nota si ho arregles, i tota la resta, el més urgent primer.

El que no fa

  • No es connecta a internet.
  • No envia res a ningú, ni tan sols si tu vols: no té cap funció que enviï dades.
  • No canvia res de la teva màquina; només escriu els seus propis informes a la seva carpeta.

El que t'ofereix

  • Un semàfor per a cada agent al qual posa nota: vermell, groc o verd.
  • «Si només fas una cosa avui»: el fitxer i el canvi exactes, i quant pujaria la teva nota si el fas.
  • La nota d'exposició: de 0 a 100 per a cada agent al qual posa nota, i com més alta, millor. Mesura fins on pot arribar l'agent amb els permisos que té avui, amb una fórmula pública; quan la fórmula canvia, l'informe ho diu.
  • El que no s'ha llegit no compta com a net: si no ha pogut llegir alguna cosa, l'informe ho diu en lloc d'amagar-ho.
  • RosmarOps proposa; el canvi el fas tu.

En quin punt és

Avui posa nota a Claude Code, Cursor i Hermes Agent a Windows. A Windows s'obre amb doble clic, i l'informe apareix al teu navegador en uns minuts. També troba Cline, GitHub Copilot, Continue, Codex, Antigravity i Claude Desktop, però encara no els posa nota.

Es pot descarregar des de GitHub, per a Windows i, en vista prèvia, per a macOS. Cada versió porta la seva empremta SHA-256, una atestació de GitHub i una compilació que qualsevol pot reproduir: com comprovar-ho.

De moment, el programa mostra l'informe en anglès o en castellà.

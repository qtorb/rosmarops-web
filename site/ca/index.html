Què poden fer els teus agents d'IA a la teva màquina.

RosmarOps llegeix la configuració dels teus agents d'IA per programar (avui Claude Code i Cursor) i dibuixa un mapa d'exposició: què pot llegir i canviar cada agent, quines claus té a l'abast i si un agent pot canviar la configuració o les instruccions d'un altre. Tot es calcula al teu ordinador.

Descarrega per a Windows

Gratuït i de codi obert (AGPL-3.0). Com comprovar que és autèntic

El que no fa

  • No es connecta a internet.
  • No envia res a ningú, ni tan sols si tu vols: no té cap funció que enviï dades.
  • No canvia res de la teva màquina; només escriu els seus propis informes a la seva carpeta.

El que t'ofereix

  • Un semàfor.
  • «Si només fas una cosa avui»: el fitxer i el canvi exactes, i quant pujaria la teva nota si el fas.
  • La nota d'exposició dels teus agents: sobre 100, una per agent, calculada amb una fórmula versionada; quan la fórmula canvia, l'informe ho diu.
  • El que no s'ha llegit no compta com a net.
  • RosmarOps proposa; el canvi el fas tu.

En quin punt és

Avui avalua Claude Code i Cursor a Windows. Detecta Cline, GitHub Copilot, Continue, Codex, Antigravity, Hermes Agent i Claude Desktop, però encara no els posa nota.

Es pot descarregar des de GitHub, per a Windows. Cada versió porta la seva empremta SHA-256, una atestació de GitHub i una compilació que qualsevol pot reproduir: com comprovar-ho.

De moment, el programa mostra l'informe en anglès o en castellà.

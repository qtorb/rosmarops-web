Claude Code a Windows: què pot fer al teu ordinador

Anthropic · CLI, Extensió d'IDE · Revisat el 28 d'octubre de 2026

Mode amb què arrenca

Mode inicial: auto

Qui decideix el que, si no, se't preguntaria: un altre model d'IA.

Mode inicial des de Claude Code 2.1.283.

Mode de permisos inicial integrat per a les sessions interactives; en mode auto, el que, si no, es preguntaria ho decideix un model, no l'usuari.

Font oficial · consultada el 24 d'octubre de 2026

Què fa RosmarOps amb aquest agent

Avaluat des de RosmarOps 0.1.0: RosmarOps llegeix la seva configuració al teu ordinador, sense xarxa, i li posa una nota d'exposició.

Revisa el teu: descarrega RosmarOps

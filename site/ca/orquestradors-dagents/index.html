Què és un orquestrador d'agents d'IA?

Un orquestrador d'agents d'IA és un programa que llança diversos agents d'IA alhora, com Claude Code o Codex, i dona a cadascun una part de la feina.

Què fa un orquestrador

Paperclip, Orca, Paseo i Claude Squad són orquestradors. Organitzen els agents com un equip: Paperclip, per exemple, els converteix en una empresa, amb organigrama, tasques i pressupost. Alguns donen a cada agent una còpia del teu projecte en una altra branca, una worktree de git, perquè els seus fitxers no es barregin.

Cada agent que llança continua sent tu

Un agent llançat per un orquestrador treballa com tu. Veu la teva carpeta personal i les teves claus, i té internet. La worktree separa els seus fitxers, no el seu abast.

Alguns els llancen sense preguntar-te

  • Paperclip arrenca Claude Code amb --dangerously-skip-permissions, així que Claude Code no et pregunta res.
  • Orca llança els agents amb accés complet de fàbrica.
  • Claude Squad té una opció per acceptar-ho tot sol. De fàbrica està apagada.
  • Paseo, de fàbrica, no fa servir el mode sense preguntes: llança Claude Code en mode auto i Codex en mode auto amb el seu sandbox.

Un orquestrador també és un servidor

Paperclip escolta al teu ordinador. Si algú el fa accessible des de fora, qualsevol que hi arribi pot crear-se un compte, perquè el registre està obert de fàbrica. Les versions anteriors a la 2026.416.0 tenen errors de seguretat greus coneguts.

Com fer-lo servir amb seny

  1. No deixis el mode sense preguntes encès per defecte: encén-lo per a una tasca i apaga'l després.
  2. Encén el sandbox a cada agent que llanci.
  3. Mira com llança els teus agents.
  4. Fes que escolti només al teu ordinador.
  5. Mantén-lo actualitzat.

Què et diu RosmarOps

Des de la versió 0.17.0, RosmarOps troba Paperclip i t'avisa quan pot posar a treballar un agent com Claude Code sense preguntar-te, quan la teva versió té un error de seguretat greu conegut, quan escolta fora d'aquest ordinador i quan qualsevol que hi arribi pot crear-se un compte. Mai no obre la base de dades de Paperclip ni els seus fitxers secrets: els coneix per la seva ruta.

De Paseo i Claude Squad llegeix, als seus propis fitxers, el mode amb què llancen cada agent. Orca guarda el que hagis triat en una base de dades que RosmarOps no obre, així que l'informe diu que suposa el valor de fàbrica, que dona als agents accés complet.

Una worktree és un sandbox?

No. Una worktree separa els fitxers de cada agent, però cada agent continua veient la teva carpeta personal i les teves claus, i té internet. Per separar el seu accés necessites el sandbox a cada agent que llanci l'orquestrador.

Per continuar

  • Què pot fer Claude Code al teu ordinador
  • Què pot fer Codex al teu ordinador
  • Encén el sandbox del teu agent d'IA en 3 passos
  • Quan un agent posa a treballar altres agents
  • Descarregar RosmarOps

RosmarOps és gratuït i de codi obert. Només llegeix, i res no surt del teu ordinador sense la teva aprovació.

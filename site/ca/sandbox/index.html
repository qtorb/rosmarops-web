Sandbox: prova un agent d'IA abans de donar-li les teves carpetes

Un sandbox és un espai tancat on un agent d'IA treballa sense poder tocar el que queda fora: la resta de les teves carpetes, les teves claus o internet. Aquí veus quins agents en porten, com encendre'l al teu i què canvia quan ho fas. RosmarOps no munta cap sandbox: et diu què podria tocar el teu agent, amb ell i sense.

Quins agents en porten

Gairebé tots els agents d'IA porten sandbox, però gairebé cap no el porta encès. A la taula veus, agent per agent i sistema per sistema, si en té, si ve encès i si talla internet.

Veure la taula

Encén-lo al teu agent

Cada plantilla és un text que copies i enganxes al teu agent: ell t'ensenya el canvi i et pregunta abans de desar-lo. Encén el sandbox, limita el que pot llegir i, on es pot, talla internet.

Antigravity CLI

macOS i Linux

Plantilla

Afegeix aquests ajustos a la meva configuració de Antigravity CLI (~/.gemini/antigravity-cli/settings.json), sense canviar res més. Ensenya'm el canvi abans de desar-lo.

{ "enableTerminalSandbox": true, "toolPermission": "proceed-in-sandbox" }

El que no cobreix

  • Els servidors MCP i la lectura de pàgines web van per les seves regles de permisos. Els dominis que permetis per llegir pàgines web queden oberts també per a les ordres del sandbox.
  • Si deixes que una ordre surti del sandbox, s'executa al teu ordinador amb tots els teus permisos.
  • Si el teu sistema no té el sandbox que necessita, l'ajust no fa res i no avisa.
Provar-ho només aquesta vegada

Obre Antigravity CLI amb el sandbox encès només per a aquesta sessió: no canvia la seva configuració i, en tancar-lo, tot torna a com estava.

agy --sandbox

Claude Code

macOS i Linux

Plantilla

Afegeix aquests ajustos a la meva configuració de Claude Code, cadascun al fitxer que indica la seva primera línia, sense canviar res més. Ensenya'm el canvi abans de desar-lo.

// ~/.claude/settings.json
{
  "permissions": {
    "defaultMode": "acceptEdits",
    "disableAutoMode": "disable",
    "disableBypassPermissionsMode": "disable",
    "blockReadsOutsideWorkingDirectories": true,
    "allow": [
      "Bash(npm run lint)", "Bash(npm run test *)",
      "Bash(git status)", "Bash(git diff)"
    ],
    "ask": [
      "Edit(~/.codex/**)", "Edit(**/.codex/**)",
      "Edit(~/.cursor/**)", "Edit(**/.cursor/**)",
      "Edit(~/.cline/**)", "Edit(**/.clinerules/**)",
      "Edit(~/.gemini/**)", "Edit(**/.gemini/**)",
      "Edit(~/.grok/**)", "Edit(**/.grok/**)", "Edit(~/.hermes/**)",
      "Edit(~/AppData/Roaming/**)",
      "Edit(**/AGENTS.md)", "Edit(**/CLAUDE.md)", "Edit(**/GEMINI.md)",
      "Edit(**/.github/copilot-instructions.md)"
    ],
    "deny": ["WebFetch", "WebSearch", "Bash(curl *)", "Bash(wget *)"]
  },
  "sandbox": {
    "enabled": true,
    "failIfUnavailable": true,
    "allowUnsandboxedCommands": false,
    "autoAllowBashIfSandboxed": false,
    "network": { "allowedDomains": ["registry.npmjs.org", "github.com"], "strictAllowlist": true },
    "filesystem": { "denyRead": ["~/.ssh", "~/.aws"] },
    "credentials": { "files": [ { "path": "~/.aws/credentials", "mode": "deny" }, { "path": "~/.ssh", "mode": "deny" } ] }
  }
}

// .claude/settings.json
{ "sandbox": { "filesystem": { "denyRead": ["~/"], "allowRead": ["."] } } }

El que no cobreix

  • El sandbox només cobreix el terminal. Les seves eines per llegir, editar i obrir pàgines web van per fora: la plantilla les limita amb les seves pròpies regles.
  • Els hooks, els servidors MCP del teu ordinador i l'ordre de la línia d'estat s'executen fora del sandbox.
  • Les ordres que posis a excludedCommands s'executen fora del sandbox.
  • Les ordres que escrius tu amb ! al davant s'executen fora del sandbox.
  • La plantilla deixa oberts registry.npmjs.org i github.com: el que el terminal llegeixi del projecte podria sortir cap a ells.
Provar-ho només aquesta vegada

Obre Claude Code amb el sandbox encès només per a aquesta sessió: no canvia la seva configuració i, en tancar-lo, tot torna a com estava.

claude --settings '{"sandbox":{"enabled":true,"failIfUnavailable":true,"allowUnsandboxedCommands":false,"autoAllowBashIfSandboxed":false,"network":{"allowedDomains":[],"strictAllowlist":true},"filesystem":{"denyRead":["~/"],"allowRead":["/RUTA/DEL/PROYECTO"]}},"permissions":{"blockReadsOutsideWorkingDirectories":true,"deny":["WebFetch","WebSearch"]}}'

Linux: Necessita: bubblewrap i socat.

Canvia /RUTA/DEL/PROYECTO per la ruta del teu projecte.

Windows

A Windows, Claude Code no té sandbox: obre'l amb un altre compte d'usuari de l'ordinador, sense les teves carpetes ni les teves claus.

Cursor

macOS i Linux

Plantilla

Als ajustos de Cursor (Settings > Agents > Approvals & Execution), tria el mode «Allowlist», deixa la seva llista buida i encén el sandbox.

Afegeix aquests ajustos a la meva configuració de Cursor, cadascun al fitxer que indica la seva primera línia, sense canviar res més. Ensenya'm el canvi abans de desar-lo.

// ~/.cursor/sandbox.json
{ "readBoundary": "workspace", "networkPolicy": { "default": "deny", "allow": ["registry.npmjs.org"] } }

El que no cobreix

  • Les ordres que afegeixis a la seva llista de permeses i la descàrrega de pàgines web s'executen fora del sandbox.
  • Pot canviar la configuració i les instruccions d'altres agents que hi hagi dins del projecte.
  • Els servidors MCP van per fora del sandbox.
  • A Linux necessita Landlock v3; si el sistema no en té, torna a preguntar-te abans de cada ordre.

Font: Anysphere, llegida el 16 de novembre de 2026.

Windows

A Windows, Cursor no té sandbox: obre'l amb un altre compte d'usuari de l'ordinador, sense les teves carpetes ni les teves claus.

Grok Build

macOS i Linux

Plantilla

Afegeix aquests ajustos a la meva configuració de Grok Build (~/.grok/config.toml), sense canviar res més. Ensenya'm el canvi abans de desar-lo.

[ui]
permission_mode = "ask"

[permission]
rules = [
  { action = "allow", tool = "bash", pattern = "npm run lint" },
  { action = "allow", tool = "bash", pattern = "npm run test *" },
  { action = "allow", tool = "bash", pattern = "git status" },
  { action = "allow", tool = "bash", pattern = "git diff" },
  { action = "deny",  tool = "webfetch" },
]
deny = ["WebSearch"]

[sandbox]
profile = "strict"

[compat.claude]
hooks = false

[compat.cursor]
hooks = false

El que no cobreix

  • A macOS, el sandbox no talla la xarxa de les ordres.
  • El sandbox no talla la connexió amb el model ni les seves eines web.
  • La cerca web pot continuar oberta: la seva documentació només confirma que es talla en arrencar-lo amb --deny WebSearch.
Provar-ho només aquesta vegada

Obre Grok Build amb el sandbox encès només per a aquesta sessió: no canvia la seva configuració i, en tancar-lo, tot torna a com estava.

grok --sandbox strict --disable-web-search --deny WebFetch

Linux: Necessita: Linux 5.13 o posterior.

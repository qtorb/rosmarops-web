Què és un servidor MCP i per què dona poder a un agent d'IA?

Un servidor MCP dona a un agent d'IA una eina nova, com llegir el teu correu o escriure al teu repositori, i a partir d'aquí l'agent pot fer tot el que permet la clau d'aquest servidor.

Què és MCP

Un agent d'IA, sol, sap llegir i escriure text. Per fer coses al món necessita eines: llegir el teu correu, consultar una base de dades, obrir una pàgina, crear una incidència. MCP és el protocol estàndard amb què un agent es connecta a eines i dades externes. Cada servidor MCP és una porta nova que obres a l'agent.

Dos tipus de porta

Un servidor local és un programa que l'agent arrenca al teu ordinador, amb el teu usuari i tot el que tu pots fer. Un servidor remot és una adreça d'internet a la qual l'agent es connecta en nom teu.

La clau

Gairebé totes les portes tenen una clau. Per entrar al teu correu o al teu repositori, el servidor necessita una clau del servei, i moltes vegades aquesta clau està escrita al mateix fitxer de configuració, al costat del servidor, en text normal. L'agent arriba exactament fins on arriba la clau: amb un servidor del teu repositori amb permís d'escriptura, pot escriure al teu repositori.

El que no és tan evident

Cada servidor explica a l'agent quines eines té i per a què serveixen. Aquesta descripció l'escriu un tercer, i l'agent la llegeix com a part de les seves instruccions. Un servidor mal fet, o amb mala intenció, li pot colar ordres per aquí.

Qui obre les portes

Tu, quan afegeixes un servidor. Però també un projecte: un repositori pot portar el seu propi fitxer de servidors. Claude Code carrega servidors de ~/.claude.json i del .mcp.json del repositori, i et demana aprovació abans de fer servir els d'un projecte. Si la dones sense mirar, la porta queda oberta.

Com fer-los servir amb seny

  1. Instal·la només servidors de qui coneixes, i treu els que ja no fas servir.
  2. Dona a cada clau el mínim permís: només lectura, si n'hi ha prou amb llegir.
  3. No acceptis els servidors d'un projecte sense veure què fan.
  4. Guarda les claus fora del fitxer de configuració quan l'agent ho permeti.
  5. Revisa de tant en tant quines portes té obertes cada agent.

Què et diu RosmarOps

RosmarOps et diu quins servidors MCP té cadascun dels teus agents, des de quin fitxer es van configurar i quines claus reconeix entre les que els arriben, sense ensenyar-les. Si el tornes a executar, et diu quins servidors són nous i quins apunten ara a un altre lloc.

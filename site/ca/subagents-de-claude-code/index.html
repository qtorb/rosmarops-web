Què poden fer els subagents de Claude Code sense preguntar-te?

Un subagent de Claude Code pot fer el que li permeti la capçalera del seu fitxer: si la capçalera no li dona eines, hereta totes les de la conversa, i pot tenir el seu propi mode de permisos, les seves pròpies ordres i els seus propis servidors MCP.

Què és un subagent

Un subagent és un encàrrec amb nom propi. Claude Code li passa una tasca, per exemple revisar codi o buscar a la documentació, i el subagent la fa amb les seves pròpies instruccions. Cadascun és un fitxer Markdown amb una capçalera YAML, a la carpeta .claude/agents/ del projecte o a la teva, ~/.claude/agents/.

Quatre coses que decideix la capçalera

  • Les seves eines. Si la capçalera no en diu cap, el subagent les hereta totes: llegir, escriure, executar ordres, sortir a internet.
  • El seu mode de permisos. Un subagent pot tenir el seu, també modes que no pregunten, com acceptEdits, auto, dontAsk o bypassPermissions. Hi ha un límit: bypassPermissions només val si la conversa principal ja el té, i si la principal està en bypassPermissions, acceptEdits o auto, el subagent hereta aquest mode i el seu s'ignora.
  • Hooks. Ordres que s'executen soles en certs moments, per exemple abans o després de fer servir una eina.
  • Servidors MCP. La capçalera pot definir servidors nous, que es connecten tan bon punt el subagent arrenca.

On viu el fitxer importa

Els hooks i els servidors MCP d'un subagent del projecte esperen que confiïs en aquesta carpeta. Els d'un subagent de la teva carpeta personal funcionen en tots els teus projectes, sense aquesta pregunta.

Per què s'obliden

Un subagent es crea en un moment i s'oblida. El copies d'un tutorial, el porta un repositori o l'instal·la una eina, i continua allà, amb els seus permisos, cada vegada que Claude Code delega.

Com fer-los servir amb seny

  1. Dona a cada subagent només les eines que necessita.
  2. No li posis un mode que no pregunta, tret que sàpigues per què.
  3. Abans de confiar en un projecte, obre la seva carpeta d'agents i llegeix les capçaleres.
  4. Vigila sobretot els de la teva carpeta personal, perquè van a tot arreu.
  5. Revisa de tant en tant quins subagents tens.

Què et diu RosmarOps

Des de la versió 0.17.0, RosmarOps llegeix només la capçalera de cada subagent de Claude Code, mai les seves instruccions. T'avisa quan un treballa sense preguntar-te, executa una ordre pròpia, es connecta a servidors MCP definits al seu fitxer o pot fer servir totes les eines. Els subagents de la teva carpeta d'usuari funcionen en tots els projectes sense la pregunta de confiança de la carpeta, i l'informe ho diu.

Tres d'aquests quatre avisos compten a la teva nota. Un subagent que pot fer servir totes les eines es mostra, però no baixa la teva nota.

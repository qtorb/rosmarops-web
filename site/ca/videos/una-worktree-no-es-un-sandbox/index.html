Transcripció

El vídeo és en castellà.

Hola, sóc la Rosmary, la presentadora virtual de RosmarOps. Si fas servir diversos agents d'IA alhora, segurament treballen en worktrees. Avui t'ensenyo per què això separa els seus fitxers, però no el que poden tocar al teu ordinador, i què fer perquè sí.

Una worktree no és un sandbox. Els orquestradors d'agents llancen diversos agents d'IA alhora sobre el teu projecte. A cadascun li donen una còpia del teu projecte en una altra branca. Això és una worktree. Serveix per a una cosa: que no es trepitgin els fitxers.

Però cada agent continua sent tu. Veu la teva carpeta personal, les teves claus i internet, sigui a la worktree que sigui. Si un README o una pàgina web li cola una instrucció amagada, l'executa amb tot això a l'abast. Un agent que pregunta abans d'actuar et dona l'oportunitat d'aturar-lo. Però alguns orquestradors, de fàbrica, els llancen sense preguntar-te res.

Aleshores, què separa de debò el seu accés? El sandbox a cada agent. Treballa en el seu projecte i no arriba al que queda fora.

Què fer? U: encén el sandbox a cada agent. Dos: mira com llança els agents el teu orquestrador. Tres: comprova què poden fer de debò. Com encendre el sandbox, agent per agent, a rosmarops.com/sandbox. I què fa cada orquestrador, a l'Observatori.

Resumint: una worktree separa els fitxers, no l'accés. Per separar l'accés, el sandbox a cada agent. Comprova què poden fer de debò, sense que res surti del teu ordinador. Ens veiem la setmana que ve.

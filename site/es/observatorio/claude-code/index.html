Claude Code en Windows: qué puede hacer en tu ordenador

Anthropic · Programa de terminal (CLI), Extensión del editor de código · Revisado el 29 de octubre de 2026

En resumen

A 29 de octubre de 2026, según su documentación, Claude Code arranca en el modo auto (desde Claude Code 2.1.283): lo que normalmente necesitaría tu permiso lo aprueba o lo bloquea otro modelo de IA, no tú.

De serie, sin preguntarte, puede leer ficheros de las carpetas en las que trabaja, ejecutar órdenes de solo lectura y consultar páginas de una lista integrada de sitios de documentación.

En Windows, guarda su configuración en 9 tipos de ficheros. En 6 de ellos pueden quedar claves escritas tal cual, sin cifrar: cualquier programa que se ejecute con tu usuario puede leerlas.

Modo con el que arranca

Modo inicial: auto

Cuando una acción necesita permiso, quién lo da: otro modelo de IA.

Modo inicial desde Claude Code 2.1.283.

Modo de permisos inicial integrado para las sesiones interactivas; en modo auto, lo que si no se preguntaría lo decide un modelo, no el usuario.

Qué hace RosmarOps con este agente

Evaluado desde RosmarOps 0.1.0: RosmarOps lee su configuración en tu ordenador, sin red, y le pone una nota de exposición de 0 a 100: cuánto puede alcanzar con los permisos que tiene hoy.

Revisa el tuyo: descarga RosmarOps

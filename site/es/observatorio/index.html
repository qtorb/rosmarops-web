Últimos cambios de seguridad

  1. 28 de octubre de 2026 · GitHub Copilot · Adónde se envían los datos

    Antes: No se había anunciado ninguna forma de seguir una misma sesión de agente en la nube desde varios sitios.

    Ahora: La misma sesión de agente en la nube se puede iniciar y seguir desde la aplicación de GitHub, VS Code, la línea de órdenes y la web. La sesión se ejecuta en la nube de GitHub. No se indica disponibilidad.

    Comprobado el 28 de octubre de 2026 con el registro de cambios oficial. Fuente oficial

  2. 28 de octubre de 2026 · GitHub Copilot · Hasta dónde llega

    Antes: No se había anunciado ninguna forma de ejecutar una misma tarea de un agente de Copilot en varios repositorios a la vez.

    Ahora: Los proyectos de Copilot ejecutan trabajo de agentes en varios repositorios en sesiones paralelas, en la aplicación GitHub Copilot, disponible desde el 28 de octubre de 2026.

    Comprobado el 28 de octubre de 2026 con el registro de cambios oficial. Fuente oficial

  3. 28 de octubre de 2026 · GitHub Copilot · Instrucciones

    Antes: No se había anunciado ninguna forma de que las automatizaciones de Copilot propusieran cambios sobre sí mismas.

    Ahora: Las automatizaciones de Copilot, flujos de trabajo de repositorio en la nube que se lanzan a mano, por eventos o con un calendario, pueden aprender de sus resultados y proponer mejoras para que el usuario las revise y apruebe. No se indica disponibilidad.

    Comprobado el 28 de octubre de 2026 con el registro de cambios oficial. Fuente oficial

  4. 27 de octubre de 2026 · GitHub Copilot · Credenciales

    Antes: No se había anunciado ninguna forma de que una GitHub App usara Copilot para una organización sin un usuario conectado.

    Ahora: Una GitHub App instalada en una organización puede pedir Copilot sin un usuario conectado, con un token de instalación de corta duración y el permiso de solo lectura «Copilot Requests». En vista previa pública; el uso se factura a la organización.

    Comprobado el 29 de octubre de 2026 con el registro de cambios oficial. Fuente oficial

  5. 27 de octubre de 2026 · Antigravity 2.28.0 · Permisos

    Antes: Elegir «Always allow» fuera de un proyecto no se guardaba, y los subagentes volvían a preguntar por órdenes o webs ya aprobadas así.

    Ahora: «Always allow» fuera de un proyecto se guarda, y los subagentes reutilizan lo que ya se aprobó así.

    Comprobado el 29 de octubre de 2026 con el registro de cambios oficial. Fuente oficial

  6. 26 de octubre de 2026 · Antigravity 2.27.0 · Modo de aprobación

    Antes: En modo auto, los subagentes y los agentes personalizados pedían aprobación para cada orden que se ejecutaba fuera del sandbox. El registro de cambios lo trata como un fallo.

    Ahora: En modo auto, los subagentes y los agentes personalizados piden aprobación solo para las órdenes fuera del sandbox que se consideran arriesgadas.

    Comprobado el 29 de octubre de 2026 con el registro de cambios oficial. Fuente oficial

Cómo trabajamos

Cada dato lleva su fuente y la fecha en que se comprobó, y se revisa a mano antes de publicarse. Nada se borra: las correcciones quedan anotadas.

Independencia

¿Qué es un orquestador de agentes de IA?

Un orquestador de agentes de IA es un programa que lanza varios agentes de IA a la vez, como Claude Code o Codex, y le da a cada uno una parte del trabajo.

Qué hace un orquestador

Paperclip, Orca, Paseo y Claude Squad son orquestadores. Organizan a los agentes como un equipo: Paperclip, por ejemplo, los convierte en una empresa, con organigrama, tareas y presupuesto. Algunos dan a cada agente una copia de tu proyecto en otra rama, una worktree de git, para que sus ficheros no se mezclen.

Cada agente que lanza sigue siendo tú

Un agente lanzado por un orquestador trabaja como tú. Ve tu carpeta personal y tus claves, y tiene internet. La worktree separa sus ficheros, no su alcance.

Algunos los lanzan sin preguntarte

  • Paperclip arranca Claude Code con --dangerously-skip-permissions, así que Claude Code no te pregunta nada.
  • Orca lanza los agentes con acceso completo de fábrica.
  • Claude Squad tiene una opción para aceptarlo todo solo. De fábrica está apagada.
  • Paseo, de fábrica, no usa el modo sin preguntas: lanza Claude Code en modo auto y Codex en modo auto con su sandbox.

Un orquestador también es un servidor

Paperclip escucha en tu ordenador. Si alguien lo hace accesible desde fuera, cualquiera que llegue a él puede crearse una cuenta, porque el registro está abierto de fábrica. Las versiones anteriores a la 2026.416.0 tienen fallos de seguridad graves conocidos.

Cómo usarlo con cabeza

  1. No dejes el modo sin preguntas encendido por defecto: enciéndelo para una tarea y apágalo después.
  2. Enciende el sandbox en cada agente que lance.
  3. Mira cómo lanza a tus agentes.
  4. Haz que escuche solo en tu ordenador.
  5. Mantenlo actualizado.

Qué te dice RosmarOps

Desde la versión 0.17.0, RosmarOps encuentra Paperclip y te avisa cuando puede poner a trabajar a un agente como Claude Code sin preguntarte, cuando tu versión tiene un fallo de seguridad grave conocido, cuando escucha fuera de este ordenador y cuando cualquiera que llegue a él puede crearse una cuenta. Nunca abre la base de datos de Paperclip ni sus ficheros secretos: los conoce por su ruta.

De Paseo y Claude Squad lee, en sus propios ficheros, el modo con el que lanzan cada agente. Orca guarda lo que hayas elegido en una base de datos que RosmarOps no abre, así que el informe dice que supone el valor de fábrica, que da a los agentes acceso completo.

¿Una worktree es un sandbox?

No. Una worktree separa los ficheros de cada agente, pero cada agente sigue viendo tu carpeta personal y tus claves, y tiene internet. Para separar su acceso necesitas el sandbox en cada agente que lance el orquestador.

¿Qué es un servidor MCP y por qué le da poder a un agente de IA?

Un servidor MCP le da a un agente de IA una herramienta nueva, como leer tu correo o escribir en tu repositorio, y a partir de ahí el agente puede hacer todo lo que permite la llave de ese servidor.

Qué es MCP

Un agente de IA, solo, sabe leer y escribir texto. Para hacer cosas en el mundo necesita herramientas: leer tu correo, consultar una base de datos, abrir una página, crear una incidencia. MCP es el protocolo estándar con el que un agente se conecta a herramientas y datos externos. Cada servidor MCP es una puerta nueva que le abres al agente.

Dos tipos de puerta

Un servidor local es un programa que el agente arranca en tu ordenador, con tu usuario y todo lo que tú puedes hacer. Un servidor remoto es una dirección de internet a la que el agente se conecta en tu nombre.

La llave

Casi todas las puertas llevan una llave. Para entrar en tu correo o en tu repositorio, el servidor necesita una clave del servicio, y muchas veces esa clave está escrita en el mismo fichero de configuración, junto al servidor, en texto normal. El agente llega exactamente hasta donde llega la llave: con un servidor de tu repositorio con permiso de escritura, puede escribir en tu repositorio.

Lo menos evidente

Cada servidor le cuenta al agente qué herramientas tiene y para qué sirven. Esa descripción la escribe un tercero, y el agente la lee como parte de sus instrucciones. Un servidor mal hecho, o con mala intención, puede colarle órdenes por ahí.

Quién abre las puertas

Tú, cuando añades un servidor. Pero también un proyecto: un repositorio puede traer su propio fichero de servidores. Claude Code carga servidores de ~/.claude.json y del .mcp.json del repositorio, y te pide aprobación antes de usar los de un proyecto. Si la das sin mirar, la puerta queda abierta.

Cómo usarlos con cabeza

  1. Instala solo servidores de quien conoces, y quita los que ya no usas.
  2. Dale a cada llave el mínimo permiso: solo lectura, si basta con leer.
  3. No aceptes los servidores de un proyecto sin ver qué hacen.
  4. Guarda las claves fuera del fichero de configuración cuando el agente lo permita.
  5. Revisa de vez en cuando qué puertas tiene abiertas cada agente.

Qué te dice RosmarOps

RosmarOps te dice qué servidores MCP tiene cada uno de tus agentes, desde qué fichero se configuraron y qué claves reconoce entre las que les llegan, sin enseñarlas. Si lo ejecutas otra vez, te dice qué servidores son nuevos y cuáles apuntan ahora a otro sitio.

Lee la configuración MCP de Claude Code, Cursor, Cline, Codex, Grok Build, Gemini CLI, GitHub Copilot, Antigravity CLI y Hermes Agent.

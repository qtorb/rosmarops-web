Glossary

The terms RosmarOps uses, in plain words. Next to them on this website you’ll see an «i»: press it and the explanation opens right there, without leaving the page.

AI agent
An artificial-intelligence program that doesn't just answer: it also does things for you, such as reading files, running commands or using your accounts.
MCP server
A piece that adds tools to an AI agent, for example to read your email or your database. Each MCP server you add widens what the agent can do.
Connector
Permission you give an agent to get into another service of yours, such as Gmail, Google Drive or GitHub. While it's connected, the agent can read or change whatever that service lets it.
Repository
A code project's folder with its full history, usually on GitHub. It also holds the instructions your agents read when they work on that project.
Key or credential
What gives access to a service in your name: a password, a token or an API key. Whoever has it can get in as if they were you.
Without asking
The agent takes the action without you approving it first. The more it works this way, the further it can go if something tricks it.
Automation
A task the agent does on its own, at a set time or when something happens, without you being there.
Train its models
Using your conversations to improve the company's AI. It doesn't change what the agent can do, but it does change who may end up seeing what you write.
Band
The part of the score set by the traffic light: 0–49 exposed, 50–79 gaps, 80–100 contained. The worst warning sets the band.
Encrypted
Turned into something only the holder of the key can read. RosmarOps encrypts your results before sending them.

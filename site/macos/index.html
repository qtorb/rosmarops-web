RosmarOps for macOS (preview)

The macOS version is a preview. The report lists what it does not check yet on macOS; none of that counts as clean. It is not signed or notarised by Apple yet, so the first time it needs two commands in Terminal.

Download the file for your Mac:

Apple silicon (M1, M2, M3, M4)Intel

Not sure which Mac you have? Apple menu > About This Mac: "Chip" means Apple silicon, "Processor" means Intel.

In Terminal, in the folder where you saved it. For Intel, use rosmarops-macos-intel instead:

cd ~/Downloads
chmod +x rosmarops-macos-apple-silicon
xattr -d com.apple.quarantine rosmarops-macos-apple-silicon
./rosmarops-macos-apple-silicon

The report opens in your browser when it finishes.

To check the download, see "Check the download" in the README.

It only reads. It never changes anything and never connects to the network.

Claude Code on Windows: what it can do on your computer

Anthropic · CLI, IDE extension · Reviewed on 28 October 2026

Mode it starts in

Starting mode: auto

Who decides what would otherwise be asked: another AI model.

Starting mode since Claude Code 2.1.283.

Built-in starting permission mode for interactive sessions; in auto mode a model, not the user, decides what would otherwise be asked.

Official source · accessed on 24 October 2026

Grok Build on Windows: what it can do on your computer

xAI · Terminal program (CLI) · Reviewed on 10 November 2026

In short

As of 10 November 2026, according to its documentation, Grok Build starts in the default mode: it asks you before what needs permission.

By default, without asking you, it can read files anywhere with its file tools, run read-only commands and search the web.

Mode it starts in

Starting mode: default

When an action needs permission, who gives it: you.

Try it in a test environment

An empty folder isn't enough: most agents can read your whole home folder, keys included. This is how to limit what Grok Build could touch:

  • Windows: open it from another user account on the computer, without your folders or keys.
  • macOS: turn on its sandbox, as its documentation explains.
  • Linux: turn on its sandbox, as its documentation explains.

A sandbox limits what it could touch; it doesn't make it harmless. In many agents it limits what it writes and where it connects, but not what it reads. With the network open, what it reads could get out.

Then run RosmarOps in that same environment: you see what the agent could touch.

Hermes Agent on Windows: what it can do on your computer

Nous Research · Terminal program (CLI), Desktop app · Reviewed on 29 October 2026 · Latest version observed: 0.22.5

In short

As of 29 October 2026, according to its documentation, Hermes Agent starts in the smart mode: what would otherwise need your permission is approved or blocked by another AI model, not by you.

By default, without asking you, it can read files anywhere with its file tools, read files anywhere on the computer from its terminal, edit files anywhere with its file tools, run commands in its terminal, reach any web address, use every tool of its MCP servers, add-ons that give it extra tools, such as access to other services, borrow other agents' logins when it has none of its own and rewrite those agents' credential files when it refreshes a borrowed login.

On Windows, it keeps its configuration in 5 kinds of files. In 4 of them, keys can be written as they are, unencrypted: any program running under your user can read them.

Mode it starts in

Starting mode: smart

When an action needs permission, who gives it: another AI model.

Commands that match a dangerous pattern go to an auxiliary model that approves, denies or asks you. Other commands run without asking in every mode, manual included.

Try it in a test environment

An empty folder isn't enough: most agents can read your whole home folder, keys included. This is how to limit what Hermes Agent could touch:

  • Windows: open it inside a container (Docker), as its documentation explains.
  • macOS: open it inside a container (Docker), as its documentation explains.
  • Linux: open it inside a container (Docker), as its documentation explains.

A sandbox limits what it could touch; it doesn't make it harmless. In many agents it limits what it writes and where it connects, but not what it reads. With the network open, what it reads could get out.

Then run RosmarOps in that same environment: you see what the agent could touch.

Latest security changes

  1. 13 November 2026 · GitHub Copilot 1.0.111 · Permissions

    Before: Before 1.0.111, the GitHub Copilot CLI changelog lists no regular expression support in enterprise-managed Shell, Bash and PowerShell permission rules.

    Now: From 1.0.111, enterprise-managed permission rules for Shell, Bash and PowerShell in GitHub Copilot CLI can use regular expressions, according to the changelog.

    Collected automatically on 14 November 2026 from the official changelog. GitHub Copilot · Official source

  2. 13 November 2026 · CodeBuddy v2.184.0 · Sandbox

    Before: Before v2.184.0, the CodeBuddy Code release notes list no switch to run osascript commands outside the macOS sandbox.

    Now: From v2.184.0, hosts other than WorkBuddy can explicitly enable running a single literal osascript command outside the macOS sandbox, under existing approvals; WorkBuddy Desktop keeps its default, according to the release notes.

    Collected automatically on 14 November 2026 from the official changelog. Official source

  3. 13 November 2026 · Antigravity CLI 1.5.8 · Sandbox

    Before: Before 1.5.8, a command could get around the path-based network rules of the terminal sandbox, according to the changelog.

    Now: From 1.5.8, the sandbox's network proxy checks every way of writing a URL path against those rules, according to the changelog.

    Collected automatically on 15 November 2026 from the official changelog. Official source

  4. 13 November 2026 · Antigravity CLI 1.5.8 · MCP

    Before: Before 1.5.8, a deny or ask rule for an MCP tool could be ignored, according to the changelog.

    Now: From 1.5.8, MCP tools loaded at start-up and the browser subagent's tools follow those rules, according to the changelog.

    Collected automatically on 15 November 2026 from the official changelog. Official source

  5. 12 November 2026 · Antigravity CLI 1.5.7 · Permissions

    Before: Before 1.5.7, the strict Tool Permission setting did not take precedence over the Auto and accept-edits modes, according to the changelog.

    Now: From 1.5.7, it takes precedence over both, and file edits still ask for your approval, according to the changelog.

    Collected automatically on 15 November 2026 from the official changelog. Official source

  6. 12 November 2026 · Antigravity CLI 1.5.7 · Hooks

    Before: Before 1.5.7, a hook that approved on its own, or an allow rule for any command, could skip a review your administrator required, according to the changelog.

    Now: From 1.5.7, they can't skip it: commands that leave the sandbox and file access outside the project under an always-ask policy always ask, according to the changelog.

    Collected automatically on 15 November 2026 from the official changelog. Official source

  7. 12 November 2026 · Antigravity CLI 1.5.7 · Approval mode

    Before: Before 1.5.7, a session with no saved mode started in Default mode, which asks you before running commands, according to the changelog.

    Now: From 1.5.7, it starts in Auto mode where it's available, also when run without a window (-p). You can keep Default in /config, according to the changelog.

    Collected automatically on 15 November 2026 from the official changelog. Official source

  8. 7 November 2026 · Qoder CN 1.39.1 · Permissions

    Before: Before 1.39.1, the changelog lists no admin console setting in Qoder CN for enterprise administrators to turn off full access mode for members.

    Now: From 1.39.1, enterprise administrators can turn off full access mode for members from the admin console, according to the changelog.

    Collected automatically on 8 November 2026 from the official changelog. Official source

  9. 6 November 2026 · OpenCode 2.2.6 · MCP

    Before: Before 2.2.6, the release notes list no MCP connection pooling in OpenCode.

    Now: From 2.2.6, pooling can be turned on for an MCP server so projects with the same setup share one connection, according to the release notes.

    Collected automatically on 7 November 2026 from the official changelog. Official source

How we work

Every fact comes with its source and the date it was checked, and each one is reviewed by hand before it is published. Nothing is deleted: corrections stay on record.

Who is in the Observatory

An agent, a framework or a tool enters if:

  1. anyone can get it;
  2. it is used to build software, or it acts for you on your computer or with your accounts;
  3. it has an official source with dates that we can read every day;
  4. it adds a way of exposure we don't cover yet.

Models are not listed on their own: the model an agent uses is part of that agent's page. RosmarOps evaluates on your computer only the agents in «On your computer». The rest are followed by the Observatory, and their page says so.

Independence

No one pays to appear. Each vendor has a right of reply, published on its page without changing what we report.

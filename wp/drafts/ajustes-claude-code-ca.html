Claude Code desa els teus ajustos personals a ~/.claude/settings.json (a Windows, %USERPROFILE%\.claude\settings.json), i els de cada projecte a .claude/settings.json, dins de la carpeta del projecte.

Els fitxers que pots tocar tu

  • Els teus ajustos, per a tots els teus projectes: ~/.claude/settings.json. A Windows, ~/.claude és %USERPROFILE%\.claude.
  • Els del projecte, compartits amb l'equip: .claude/settings.json, a la carpeta del projecte. Es pugen a git amb la resta del codi.
  • Els teus en aquest projecte: .claude/settings.local.json. Quan Claude Code crea aquest fitxer, configura git perquè l'ignori.
  • La resta de la configuració: ~/.claude.json. Desa les dades del teu compte, la configuració dels servidors MCP, l'estat de cada projecte (com les decisions de confiança) i les opcions globals que escriu /config.
  • Els servidors MCP del projecte: .mcp.json, a la carpeta del projecte.

Els que posa la teva empresa

Els ajustos gestionats no els crees ni els edites tu, i cap ajust d'usuari o de projecte els anul·la. Si n'hi ha, són aquí:

  • macOS: /Library/Application Support/ClaudeCode/managed-settings.json
  • Linux i WSL: /etc/claude-code/managed-settings.json
  • Windows: C:\Program Files\ClaudeCode\managed-settings.json. Claude Code no llegeix la ruta antiga, C:\ProgramData\ClaudeCode\managed-settings.json.

També poden arribar per la gestió de dispositius del sistema (a macOS, el domini com.anthropic.claudecode; a Windows, el registre, a HKLM\SOFTWARE\Policies\ClaudeCode o HKCU\SOFTWARE\Policies\ClaudeCode) o des de la consola d'administració de Claude.

Quin mana

De més fort a més feble: els gestionats, el que passes amb --settings en arrencar, els teus al projecte, els del projecte i, per últim, els teus ajustos d'usuari.

Què convé mirar

settings.json i .claude.json poden tenir claus sense xifrar. Obre'ls i mira què hi ha. A la fitxa de Claude Code de l'Observatori tens què desa cadascun i què fa Claude Code de fàbrica.

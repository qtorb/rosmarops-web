Claude Code guarda tus ajustes personales en ~/.claude/settings.json (en Windows, %USERPROFILE%\.claude\settings.json), y los de cada proyecto en .claude/settings.json, dentro de la carpeta del proyecto.

Los ficheros que puedes tocar tú

  • Tus ajustes, para todos tus proyectos: ~/.claude/settings.json. En Windows, ~/.claude es %USERPROFILE%\.claude.
  • Los del proyecto, compartidos con el equipo: .claude/settings.json, en la carpeta del proyecto. Se suben a git con el resto del código.
  • Los tuyos en ese proyecto: .claude/settings.local.json. Cuando Claude Code crea este fichero, configura git para que lo ignore.
  • El resto de la configuración: ~/.claude.json. Guarda los datos de tu cuenta, la configuración de los servidores MCP, el estado de cada proyecto (como las decisiones de confianza) y las opciones globales que escribe /config.
  • Los servidores MCP del proyecto: .mcp.json, en la carpeta del proyecto.

Los que pone tu empresa

Los ajustes gestionados no los creas ni los editas tú, y ningún ajuste de usuario o de proyecto los anula. Si existen, están aquí:

  • macOS: /Library/Application Support/ClaudeCode/managed-settings.json
  • Linux y WSL: /etc/claude-code/managed-settings.json
  • Windows: C:\Program Files\ClaudeCode\managed-settings.json. Claude Code no lee la ruta antigua, C:\ProgramData\ClaudeCode\managed-settings.json.

También pueden llegar por la gestión de dispositivos del sistema (en macOS, el dominio com.anthropic.claudecode; en Windows, el registro, en HKLM\SOFTWARE\Policies\ClaudeCode o HKCU\SOFTWARE\Policies\ClaudeCode) o desde la consola de administración de Claude.

Cuál manda

De más fuerte a más débil: los gestionados, lo que pasas con --settings al arrancar, los tuyos en el proyecto, los del proyecto y, por último, tus ajustes de usuario.

Qué conviene mirar

settings.json y .claude.json pueden tener claves sin cifrar. Ábrelos y mira qué hay. En la ficha de Claude Code del Observatorio tienes qué guarda cada uno y qué hace Claude Code de fábrica.

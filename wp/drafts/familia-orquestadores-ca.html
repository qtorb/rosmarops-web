Un orquestrador o una eina d'automatització posa a treballar diversos agents d'IA per tu. El que cada agent pot fer sense preguntar ja no ho decideixes a l'agent.

Si fas servir un agent d'IA per programar, ja saps com va: li demanes alguna cosa, et pregunta abans del que és important, i tu decideixes. Cada agent porta les seves preguntes i els seus ajustos.

El pas següent és no llançar-lo tu. Hi ha productes que ho fan per tu: reparteixen una tasca entre diversos agents, els engeguen a una hora o quan arriba un correu, i segueixen quan no mires. Són de tres tipus:

  • Orquestradors, que coordinen diversos agents com si fossin un equip.
  • Automatització de fluxos, que encadena passos i serveis i hi posa agents a dins.
  • Constructors sense codi, on muntes un agent sense programar.

Uns s'instal·len al teu ordinador o al teu servidor. D'altres es contracten al núvol del fabricant.

El que canvia

Quan l'agent el llances tu, les seves preguntes t'arriben a tu. Quan el llança un altre programa, aquest programa decideix amb quins ajustos arrenca, quines claus li passa i si les seves preguntes arriben a algú.

Així que el que un agent pot fer sense preguntar ja no es decideix a l'agent. Es decideix al producte que el llança. I és fàcil no veure-ho: segueixes pensant en el teu agent de sempre, amb les seves preguntes de sempre, i ja no és així.

Les set preguntes

Són les del mínim de control de RosmarOps. Es contesten amb sí o no, amb la documentació oficial del producte, el seu codi públic o una prova:

  1. De fàbrica. Diu què pot fer un agent sense preguntar-te, tal com ve?
  2. Les preguntes dels agents. Si llança agents fets per altres, conserven les seves preguntes, o diu clarament que les treu?
  3. Què hereta cada agent. Diu quina carpeta, quin entorn i quines claus rep cadascun?
  4. Les claus. Es desen per connexió, es poden retirar una a una, i diu si l'agent les veu?
  5. Sense ningú davant. Pots veure la llista del que arrenca sol i apagar cada cosa?
  6. Aturar. Pots aturar un agent, i tots alhora?
  7. Avisos de seguretat. Publica els seus avisos en un lloc fix i diu com comunicar-li una fallada?

No totes s'apliquen a tots els productes. La segona només compta si el producte llança agents d'altres; la tercera, si corre a la teva màquina.

Per què preguntes de sí o no

Perquè no mesurem si un producte és bo. Mesurem si qui el fa servir pot saber què fa. Un producte pot estar molt ben fet i no dir-ho enlloc; per a qui l'instal·la, el resultat és el mateix que si no ho estigués.

I perquè una resposta que falta gairebé sempre s'arregla amb una pàgina de documentació. Per això avisem el fabricant catorze dies abans de publicar i li diem quina línia canviaria el resultat.

Què pots fer avui

Si ja fas servir un orquestrador o una eina d'automatització amb agents a dins, busca a la seva documentació la primera pregunta: què fa un agent sense preguntar-te, tal com ve. És la que més canvia d'un producte a un altre.

He mesurat nou agents d'IA tal com vénen instal·lats. El mapa de l'Observatori ensenya quant pot fer cadascun sense preguntar-te, i per què.

Per què un mapa

Quan instal·les un agent d'IA, no ve amb una fitxa que digui què pot fer sense preguntar-te. Aquesta informació existeix, però està repartida entre la documentació, els fitxers de configuració i el codi de cada fabricant. El mapa l'ajunta en un sol lloc.

Com ho mesurem

Instal·lem cada agent tal com ve, al mateix Windows de prova i amb els seus valors de sèrie. Mesurem sis coses, de 0 a 3: autonomia, abast, contagi, delegació, opacitat i complexitat. D'aquí en surt una classe, de l'A («fa poc sense preguntar-te») a la D («fa molt sense preguntar-te»), i una nota de fàbrica de 0 a 100: com més alta, menys exposat.

No ho calculo a mà: ho calcula RosmarOps amb cada versió, i les dades es publiquen.

El que surt avui

Amb RosmarOps 0.11.4, el 13 de novembre:

  • Classe D: Claude Code, Cursor, Cline a VS Code i Hermes Agent.
  • Classe C: Codex i Grok Build.
  • Classe B: GitHub Copilot a VS Code, Gemini CLI i Antigravity CLI.
  • Classe A: cap.

Totes les classes són provisionals, perquè encara no mesurem la complexitat. Quan falta una dada, no compta com a bona.

Tres coses que es repeteixen

  • Cada cop decideix més un model. Diversos agents ja vénen preparats perquè una altra IA aprovi les seves accions en lloc de preguntar-te.
  • El fitxer que tots llegeixen. Un mateix fitxer d'instruccions, com AGENTS.md, el llegeixen diversos agents alhora.
  • El que no es pot revisar. Alguns guarden els seus permisos dins l'aplicació, on ni tu ni RosmarOps no els podeu comprovar.

El que el mapa no diu

No diu si un agent és segur o no. Diu quant pot fer sense tu. El que et convé depèn de per a què el facis servir.

I és cada agent de fàbrica. El teu pot ser diferent: depèn de com el tinguis configurat, de les claus que hi hagi al teu ordinador i dels altres agents que facis servir. Per veure-ho hi ha RosmarOps: a Windows, des de la Microsoft Store; a Mac (vista prèvia) i a Linux, des del web.

Mira el mapa d'agents d'IA. I si veus alguna cosa que no quadra, explica-m'ho.

I measured nine AI agents as they come installed. The Observatory map shows how much each one can do without asking you, and why.

Why a map

When you install an AI agent, it doesn't come with a sheet saying what it can do without asking you. That information exists, but it is spread across each vendor's documentation, configuration files and code. The map puts it in one place.

How we measure it

We install each agent as it comes, on the same test Windows machine and with its default settings. We measure six things, from 0 to 3: autonomy, reach, contagion, delegation, opacity and complexity. That gives a class, from A (“does little without asking you”) to D (“does a lot without asking you”), and a factory score from 0 to 100: the higher, the less exposed.

I don't work it out by hand: RosmarOps calculates it with each release, and the data is published.

What it shows today

With RosmarOps 0.11.4, on 13 November:

  • Class D: Claude Code, Cursor, Cline in VS Code and Hermes Agent.
  • Class C: Codex and Grok Build.
  • Class B: GitHub Copilot in VS Code, Gemini CLI and Antigravity CLI.
  • Class A: none.

Every class is provisional, because we don't measure complexity yet. When a piece of data is missing, it never counts as good.

Three things that keep coming up

  • A model decides more and more. Several agents now come ready for another AI to approve their actions instead of asking you.
  • The file everyone reads. One instructions file, like AGENTS.md, is read by several agents at once.
  • What can't be checked. Some keep their permissions inside the app, where neither you nor RosmarOps can check them.

What the map doesn't say

It doesn't say whether an agent is safe. It says how much it can do without you. What suits you depends on what you use it for.

And it is each agent out of the box. Yours may be different: it depends on how you have set it up, on the keys on your computer and on the other agents you use. That is what RosmarOps is for: on Windows, from the Microsoft Store; on Mac (preview) and Linux, from the website.

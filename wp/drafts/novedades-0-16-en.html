RosmarOps 0.16.0 is out. It doesn't add a new agent. It changes what you see when you open the report, and it fixes what our first Linux testers ran into.

The report now opens in three blocks

Until now, a review could end in a long list of findings, one per file and per agent. Many of them were the same problem seen from different places. The report now opens with three blocks:

  1. Your result: the score and what it means.
  2. Your problems: findings grouped by the problem behind them. Several findings about the same setting become one problem, with the places where it shows up.
  3. How to stop them coming back: the setting to change, and the template you can paste into your agent.

You read less and you know where to start.

Updates that explain themselves

When RosmarOps changes, it checks that the new version is really the one you installed. That check now asks you in your language, in every command, instead of stopping with a message in English. And if RosmarOps has to start from scratch, it tells you first that your computer will show up as a new one in your space.

Linux: reports you can open

On Ubuntu, Firefox from the Snap store couldn't open reports saved in a hidden folder. Reports are now saved in ~/RosmarOps, and your earlier ones are moved there once.

Smaller things that save time

  • A review no longer ends asking you to pick findings by number. When you want to dismiss or accept one, run rosmarops findings.
  • When a project takes too long to review, the report says «at least N findings» and how many projects were not finished, instead of a number that looks complete.
  • On Linux, RosmarOps also reads Cursor's company hooks file and its command-line settings, where Cursor itself looks for them.

Tested before it reaches you

Every version is now installed from scratch and updated from the previous one, on Windows, macOS and Ubuntu, before it is published. If one of those journeys fails, the version doesn't ship. It already stopped one release this week.

How to get it

  • Windows: from the Microsoft Store, or from GitHub.
  • macOS and Linux: brew install qtorb/rosmarops/rosmarops, or download it from GitHub.

If you already use RosmarOps, update and run a review: the first screen is the new one.

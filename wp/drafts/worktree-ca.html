Llegint el README de Paradev, un programa que posa a treballar diversos agents d'IA alhora, vaig trobar una frase que em va fer aturar. Després d'explicar que cada agent treballa a la seva pròpia worktree i a la seva pròpia branca, diu: «worktrees do not sandbox processes». Les worktrees no aïllen el que fan els agents.

Em va semblar honest per part seva. I em va fer pensar en quanta gent fa servir worktrees creient el contrari.

Què és una worktree

Si treballes amb diversos agents alhora, el més probable és que cadascun tingui la seva. Una worktree és una altra còpia de treball del teu repositori, en una altra carpeta i en una altra branca. Orquestradors com Orca, Paseo, Claude Squad o Paradev en reparteixen una a cada agent perquè no es trepitgin els fitxers: un arregla un error a la seva carpeta mentre un altre escriu una funció a la seva. Funciona, i és una bona idea.

El que no separa

Però l'únic que separa són els fitxers del projecte.

Cada agent continua corrent amb el teu usuari. Veu la teva carpeta personal, les teves claus (les de .ssh, les del núvol, les dels teus .env), les sessions que tens obertes en altres agents, i internet. Si una pàgina web o un README li passa d'amagat una instrucció, l'executa amb tot això a mà, sigui a la worktree que sigui.

Per què ara importa més

Un agent que et pregunta abans de cada ordre et dona l'oportunitat de dir que no. Diversos orquestradors treuen aquesta oportunitat de fàbrica, perquè la feina en paral·lel no s'encalli. Orca llança els agents amb accés complet per defecte. Paradev fa el mateix amb Claude Code, Codex i uns quants més.

Cinc agents alhora, cap no pregunta, i entre ells i les teves claus només hi ha una carpeta diferent.

Què faria jo

Tres coses, per aquest ordre.

  1. Encendre el sandbox a cada agent que llanci l'orquestrador. El sandbox sí que separa l'accés: segons l'agent, deixa d'arribar a la teva carpeta personal o a internet. Com fer-ho, agent per agent, és a la guia del sandbox.
  2. Mirar amb quin mode arrenca el teu orquestrador cada agent. Què fa cadascun de fàbrica ho tens a l'Observatori.
  3. Fer servir RosmarOps. Troba Paperclip, Paseo, Claude Squad i Orca, i et diu quins agents poden posar a treballar sense preguntar-te i a quines claus arriben. Sense que res surti del teu ordinador.

Reading the README of Paradev, a program that puts several AI agents to work at once, I came across a sentence that made me stop. After explaining that each agent works in its own worktree and on its own branch, it says: "worktrees do not sandbox processes". Worktrees don't isolate what the agents do.

It struck me as honest of them. And it made me think of how many people use worktrees believing the opposite.

What a worktree is

If you work with several agents at once, each one most likely has its own. A worktree is another working copy of your repository, in another folder and on another branch. Orchestrators such as Orca, Paseo, Claude Squad or Paradev hand one to each agent so their files don't clash: one fixes a bug in its folder while another writes a feature in its own. It works, and it's a good idea.

What it doesn't separate

But the only thing it separates is the project's files.

Each agent still runs as your user. It sees your home folder, your keys (in .ssh, for the cloud, in your .env files), the sessions you have open in other agents, and the internet. If a web page or a README slips it an instruction, it runs it with all of that at hand, whatever worktree it's in.

Why it matters more now

An agent that asks you before each command gives you the chance to say no. Several orchestrators remove that chance by default, so parallel work doesn't get stuck. Orca launches agents with full access by default. Paradev does the same with Claude Code, Codex and several others.

Five agents at once, none of them asking, and between them and your keys there's only a different folder.

What I'd do

Three things, in this order.

  1. Turn on the sandbox in every agent the orchestrator launches. The sandbox does separate access: depending on the agent, it stops reaching your home folder or the internet. How to do it, agent by agent, is in the sandbox guide.
  2. Check which mode your orchestrator starts each agent in. What each one does by default is in the Observatory.
  3. Run RosmarOps. It finds Paperclip, Paseo, Claude Squad and Orca, and tells you which agents they can put to work without asking you and which keys those agents can reach. Without anything leaving your computer.

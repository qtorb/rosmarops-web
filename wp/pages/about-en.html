RosmarOps shows what the AI coding agents on your computer can do: what each one can read and change, which keys it can reach, where its MCP servers send data, and whether one agent can change another agent’s configuration or instructions. Everything is computed on your computer. It is made by Albert Garcia Pujadas.

What it is today

A free program for Windows, open source under the AGPL-3.0 licence, that you download from GitHub (latest release). It reads the configuration your agents leave on disk and gives you a report with a traffic light, «If you do only one thing today», and an Agent Posture Score out of 100 for each agent it evaluates.

Today it evaluates Claude Code and Cursor. It detects Cline, GitHub Copilot, Continue, Codex, Antigravity, Hermes Agent and Claude Desktop, but doesn’t score them yet. More on the home page.

What it never does

  • It never connects to the internet. The program contains no networking code, not even to check for updates.
  • It never sends telemetry: not anonymous, not opt-in.
  • It never changes your files, settings, keys or agents. The report tells you what to change; you make the change.
  • It never shows a key in full: only its first and last four characters.
  • It only writes in its own folder (~/.rosmarops/) and in the reports folder you choose.

You don’t have to take our word for it. The trust model lists every claim and how to check it. Each release comes with a GitHub attestation of the commit and workflow that built it, and building the same version from its source, with the Go version and command we document, gives the same program.

What it doesn’t do yet

  • The program isn’t signed with a code-signing certificate, so Windows may warn you the first time you open it.
  • No independent security review has been published.
  • It reads configuration at rest. It doesn’t see what an agent does while it runs, settings kept only inside an app or on a vendor’s servers, or anything set only in one terminal session. What it couldn’t read is listed in the report and never counts as clean.
  • It runs only on Windows.

Where it comes from

RosmarOps began in March 2025 as a research blog, in Spanish, around one question: what can an AI system do that you don’t expect, and who decides what it reads. It has published more than a hundred articles along four lines:

  • Adversarial SEO and AI SEO: how what search engines and assistants read, cite and recommend gets manipulated.
  • Information warfare: how AI makes disinformation and influence operations cheaper.
  • AI security: attacks on models, data poisoning and prompt injection.
  • Agents and autonomy: what changes when AI stops answering and starts acting.

From March 2026 the blog focused more and more on agents, because with AI coding agents that question reached the computer of the people who build: an agent reads files, runs commands and edits code with your permissions. The product came out of that. To see how we got there (in Spanish):

  • El agente que no sabe con quién habla (The agent that doesn’t know who it’s talking to)
  • La capa de inferencia (The inference layer: when approving is no longer the same as deciding)
  • MCP no es un plugin (MCP is not a plugin: agents’ new chain of trust)
